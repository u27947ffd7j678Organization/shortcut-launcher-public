# アプリケーション仕様

## 基本仕様

Shortcut Launcher は、登録済みショートカットを「アプリ」と「URL」の2つのタブに分けて表示します。各項目はボタンとして表示され、クリックすると対象のアプリケーションまたはURLを開きます。

## タブ構成

| タブ | 役割 | 受付対象 |
| --- | --- | --- |
| アプリ | ローカルアプリケーションの登録・起動 | `.exe`, `.lnk` |
| URL | WebページやURLショートカットの登録・起動 | `http://`, `https://`, `.url` |

ドラッグアンドドロップはウィンドウ全体で受け付け、ドロップされた内容の種類に応じてアプリタブまたはURLタブへ振り分けます。

## ドラッグアンドドロップ時の動作

### `.exe`

`.exe` ファイルをドロップすると、アプリ項目として登録されます。

- 表示名: 拡張子を除いたファイル名
- 保存先: `user_data/items.json`
- アイコン: 実行ファイルから抽出して `user_data/icons/{アプリ名}.png` に保存
- 重複判定: 同じ `path` が既に登録されている場合は追加しない

### `.lnk`

`.lnk` ファイルをドロップすると、リンク先を解決します。リンク先が `.exe` の場合、その実行ファイルをアプリ項目として登録します。

- 表示名: 解決後の `.exe` のファイル名
- 保存形式: `.exe` と同じ
- リンク先が `.exe` ではない場合は登録対象外

### URL文字列

`http://` または `https://` で始まるURLは、URL項目として登録されます。

- 表示名: URLからプロトコルを除いたホスト名部分
- 保存先: `user_data/items.json`
- 重複判定: 同じ `url` が既に登録されている場合は追加しない

### `.url`

`.url` ファイルをドロップすると、ファイル内の `URL=` で始まる行を読み取り、その値をURL項目として登録します。

## JSON保存形式

登録情報は `user_data/items.json` に配列形式で保存されます。

### アプリ項目

```json
{
  "type": "app",
  "name": "ExampleApp",
  "path": "C:\\Path\\To\\ExampleApp.exe",
  "icon": "C:\\Path\\To\\user_data\\icons\\ExampleApp.png"
}
```

| キー | 内容 |
| --- | --- |
| `type` | 項目種別。アプリの場合は `app` |
| `name` | 画面に表示する名前 |
| `path` | 起動する `.exe` のパス |
| `icon` | 抽出したアイコン画像の保存パス |

### URL項目

```json
{
  "type": "url",
  "name": "example.com",
  "url": "https://example.com"
}
```

| キー | 内容 |
| --- | --- |
| `type` | 項目種別。URLの場合は `url` |
| `name` | 画面に表示する名前 |
| `url` | ブラウザで開くURL |

## 起動処理

| 項目種別 | 起動方法 |
| --- | --- |
| アプリ | 保存された `path` をWindowsの既定動作で開く |
| URL | 保存された `url` を既定ブラウザで開く |

## 並び替え

各タブ内の項目はドラッグで並び替えできます。並び替え後は `items.json` に保存されます。

保存時は、アプリタブの項目、URLタブの項目の順でJSON配列が再構成されます。

## 削除

各項目には削除ボタンがあります。削除すると対象項目が `items.json` から除外され、画面表示も更新されます。

## 初回起動時の挙動

起動時に `user_data/` と `user_data/icons/` が存在しない場合は自動作成されます。`items.json` が存在しない場合は、以下の内容で初期化されます。

```json
[]
```

## エラーログ

例外が発生した場合は、アプリケーションの配置ディレクトリに `error_log.txt` が出力されます。ログには発生日時、処理名、例外内容、トレースバックが記録されます。
