# Shortcut Launcher

Shortcut Launcher は、よく使うアプリケーションやURLを登録し、タブごとに整理して起動できるWindows向けショートカットランチャーです。

このリポジトリは、privateリポジトリで管理している実装内容を外部向けに説明するための公開用ドキュメントです。ソースコードやビルド可能なファイルは含めていません。

## 概要

Shortcut Launcher では、`.exe`、`.lnk`、URL、`.url` ファイルをドラッグアンドドロップで登録できます。登録した項目はアプリタブとURLタブに分かれて表示され、クリックすると対象のアプリケーションまたはURLを開きます。

登録情報はローカルのJSONファイルに保存されます。アプリケーション項目では実行ファイルのパスと抽出したアイコン情報を保持し、URL項目ではURL文字列を保持します。
